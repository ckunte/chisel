About this site, etc. {% markdown %} {#Hello. I am {{ site_author }}, an {{ bio }}, and producer of this little website — my sandbox for code and prose. I am not on social media; any match there must be a namesake. (Exceptions: GitHub, LinkedIn.) #}This domain exists mainly to be a pointer to MX records. I put the idling A record to use, mostly as an afterthought,[^1] which turned-on the lights here. Built with [Chisel][c1], this site respects [web standards][ws], produces valid [HTML][v1], [CSS][v2], and [RSS][v3] mark-ups, and is [friendly] to phones and small screens. For accessibility, handy keyboard shortcuts are available. On MacOS, hold-down Ctrl Opt and press a _key_ from the list below. Similarly, on Linux and Windows, hold-down Alt and press a _key_: | Key | Link | Works on | | ------------ | ------------ | ----------------- | | / | Home | All pages | | a | About | Home | | j | Latest, Prev | Home, Archive, Notes | | k | First, Next | - do - | | r | Archive | Homepage | _Syndication._ [RSS][f1] feed channel is available to keep up with the latest published. _Code._ To ensure it works as intended, all published code is pre-tested without exceptions. Older code snippets may contain [legacy python code][p2]. These should still work with last of python v2. Most personal projects are in [repositories][gh] and in [gists][gs]. _Credits._ To Armin Ronacher and team for [Jinja]; David Zhou for [Chisel]; Guido van Rossum + community of volunteers for [python]; Ivan Sagalaev and team for [hl.js]; Linus Torvalds, Junio Hamano + community of volunteers for [git]; [GitHub] for hosting; Emily Eisenberg and Sophie Alpert for [KaTeX]; Manfred Stienstra, Yuri Takhteyev, and Waylan Limberg for [markdown in python]. _Privacy._ Visitors are not tracked, and there are no advertisements, no cookies, and no trackers served. _TLS._ Transport layer security is available as an option, but not auto-redirected from http to https. This is by intent to enable low bandwidth users to make the best use of cache and help with speed-loading.{#To understand why, see [Roy Fielding's remark][rf].#} _Disclaimer, Terms of use._ I do not speak for my employer.
