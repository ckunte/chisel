About this site, etc. {% markdown %} Hello. I am {{ site_author }}, an {{ bio }}, and producer of this little website. It is my sandbox for code and prose.[^1] I am a native of India, and I currently live and work in Perth, Australia. {# #} This domain exists mainly to be a pointer to MX records. I put the idling A record to use, mostly as an afterthought, which turned-on the lights here.
